# Visual sources and credits

All images used by the profile README are stored in this repository. No external image service is required to render the profile.

## Original profile design

The two header SVGs and six navigation badges were created for this profile. The palette uses navy, blue, violet and turquoise. The README selects a header for the viewer's preferred color scheme using GitHub-supported `<picture>` markup.

## Technology icons

The original logo artwork comes from [Devicon](https://github.com/devicons/devicon), except Google Gemini, which comes from [Simple Icons](https://github.com/simple-icons/simple-icons).

- Devicon source pattern: `https://raw.githubusercontent.com/devicons/devicon/master/icons/<name>/<name>-original.svg`.
- Gemini source: [googlegemini.svg](https://github.com/simple-icons/simple-icons/blob/develop/icons/googlegemini.svg).
- Downloaded on 24 November 2026. Logos are wrapped in labelled, neutral-background SVG chips for readability on both light and dark pages. The Gemini glyph uses the brand's violet color.
- [Devicon MIT license](licenses/devicon.txt).
- [Simple Icons CC0 license](licenses/simple-icons.txt).

Technology names and logos belong to their respective owners. Their inclusion identifies project technologies and does not imply endorsement.
